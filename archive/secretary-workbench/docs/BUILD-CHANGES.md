# 本交接副本的变换

运行中的源码/服务不因本包变换而改变。本包不是复制个人环境：

- 按文件白名单选代码、契约、测试、Skill和最小MIT协议参照；排除历史/DB/runtime/原件/真实基线与授权文件。
- 真实路径、微信身份/群范围、thread和个人名称替换为环境配置、通用路径或一致合成标识；个人背景和旧业务规则改为模板/通用方法。
- 跨项目模块改为仓库内相对引用，显式SSH主机/代码/状态路径可配置；不把认证放入URL。
- 只提取V2真正依赖的原生编辑器/文件预览/回执函数，排除原个人业务服务和发布范围。
- 已退役部署/现场入口以不可执行文本存档；纯service模板可导入，不自动安装；示例不启用timer或模型。
- 演示网页模型执行默认关闭，需显式命令行opt-in；已有库中显式模型运行代码仍保留，不能当作已经配置可执行实例。
- 测试固定时钟、合成字体与只读visible扫描fake做了相容修正；不降低未知结果不重发、身份和事务保护断言。
- 生成本仓README、安装/许可/验证索引、合成演示、包检查工具和空白工作区模板。

Mac采集器/foundation由独立仓库另交，外部连接器/模型/字体/OCR/官方客户端按各自授权安装。新实例的实际媒体和渠道全链必须另验收，不把本次代码上传当成通过。

兼容server.py不再隐式选择用户Library数据库或来源，要求两个路径显式提供；正常本地演示仍走新工作区入口。
