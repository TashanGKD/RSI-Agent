# Mac读取适配

源码为wechat_read.py/voice.py/late.py，先运行各自--help。配置WECHAT_MAC_ACCOUNT_ID与WECHAT_MAC_FOUNDATION；后者需要独立Mac采集器提供crypto/security/library纯解码函数。本仓不提供该工程、模型或授权材料。

inspect仅元数据，export在明确时间窗/输出新文件后有界取得；语音用同一会话与serverId。新输出拒绝覆盖、保留账号/源文件/哈希/coverage；没有正文或媒体不能冒称已读。默认工具不更新记事本，不发送消息，不重建全库，不启动常驻进程。来源新格式/权限变化/上限失败时保留缺口。
