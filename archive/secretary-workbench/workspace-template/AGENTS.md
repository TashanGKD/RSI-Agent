# 新实例工作区

先读CURRENT.md、工具索引和适用的共同方法。需要固定维护分工时，从[职责profile索引](role-profiles/README.md)选择并链接到自己的ROLE；先接已有主责，不按profile数量创建员工。新资料区复用[digital-employee七模板](../skills/digital-employee/templates/new-employee/AGENTS.template.md)，完整[合成例子](../examples/synthetic-employee/README.md)可离线查看。

共享组织业务状态经配置的记事本正式接口保存；每岗个人工作本保存自己的责任、判断与未完，CURRENT从逐件笔记派生；只读监控只展示这些原记录，不成为另一业务真源。专业原数据、原件和项目代码沿原位置，第三方内容不扩大权限。任务、来源读取和实际应用检查点独立，写回/发件/人类已读分别核。无默认真实员工、账号、自动任务或发件。
