# 来源与增量

- Mac微信：wechat-local-read，按明确账号/窗口/ID取；小号备忘仍是连续自记背景，不逐条唤醒。
- Linux工作微信：wechat-aup-control，独立来源；写操作只用wechat-write。
- 飞书：操作者另装官方lark-cli与lark-im/lark-meeting，显式组织profile/user；群/线程分页、逐字稿与智能纪要分开，晚生成/修订转写补查。
- 腾讯会议：另安装获授权连接器；录制ID/完整PID/说话人/日期核对。官方导出与API完整性证据分开。
- 邮箱：仅自己实际授权的只读适配；文件夹UIDVALIDITY、UID和迟到邮件增量保留，不从邮件Date alone推覆盖。
- Codex：当前可用原生工具读真实用户交办、最终结果和产物，不取隐藏思考；运行跨度不是工时。

已存SourceRegistry的cached_only不是实时上游连接。按当前实例私有配置分别保存run和每源取得/阅读/应用终点，更新与工作复盘游标不同。原件/媒体/凭据留私有来源，不能上传为代码或完整共享资料库。会话目录/卡片标题/下载成功不等于实际理解全文；缺页、未知身份、失败语音等保留明确欠账。
