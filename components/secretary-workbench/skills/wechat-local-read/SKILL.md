# 本机微信读取

> Portable copy: original operator authorization and installation state are not included. Configure your own existing tools and permitted channels; examples do not grant access or establish live capability.

读取与事项判断分开：本技能取得来源；调用者负责理解内容、匹配事项、追加依据。输出不是“已全部阅读”的证明。

## 已验证入口

本机工具目录：
`/opt/secretary-workbench/notebook/tools/`

独立于事项服务；不开事项网页也可运行。先读相应工具的 `--help` 和 [读取约定](/opt/secretary-workbench/notebook/tools/WECHAT-README.md)。使用已有环境：

`python3`

- `wechat_read.py inspect`：核对支持的消息源目录及文件元数据。
- `wechat_read.py export --from <UTC秒时间> --to <UTC秒时间> --output <新的私有JSONL路径>`：按左闭右开窗口，读取所有会话消息。边界必须明确；单窗最多31天。输出父目录须存在，不覆盖文件。
- `wechat_late.py`：补核晚导入旧消息或旧ID内容变化。使用前读其帮助及源码约定，不能只按消息时间过滤后就声称没有晚导入。
- `wechat_voice.py`：对既有导出中至多6条语音，按真实会话和非零serverId定位本地音频、解码并尝试已有离线转写。先读帮助；不按近似时间凑配。

默认不带子命令只显示帮助。不要重写页面解密、WAL校验或语音关联逻辑；复用已测试工具。

## 判断读取是否成功

1. 核对导出及相邻receipt：账号、源库清单、时间窗口、每源成功／失败、消息数量、文件哈希与实际最晚消息。
2. 本机派生库可能落后于官方微信。明确区分库最新消息、读取截止、正文读完位置；不要把应用刷新时间作为微信更新时刻。
3. 保留稳定消息ID、真实发送人、原时间、会话、来源文件／表／本地ID。分批按完整会话阅读，关键词仅用于定位，不能替代正文阅读。
4. 图片、文件、视频、卡片标题与占位不等于内件读完。仅按问题定向读有关媒体；文件用原消息MD5和大小绑定，不能只凭同名。
5. ASR文本不等于人工核听。错词、人名、金额、期限或不可理解输出保留待核，不把乱码强解释成任务。

## 资源与权限边界

工具仅复用已经授权的本地来源和私有已存密钥，不显示、复制或上传密钥。原始XML可能含媒体访问属性，不将其散布到报告或共享材料。

只读原库；单源临时副本有1.2GB上限、有限超时和清理。不运行常驻采集器，不复制整个聊天／媒体库，不启动全库重建。来源变化、轮换密钥或权限不足时保存明确失败与未读范围，不绕过权限或改系统设置。

不要将导出成功、ASR成功或测试通过等同于所有语义事项已找到。写事项时交给现有事项维护流程，不在本读取工具里混入业务判断、确认或外发动作。
