# 官方微信操作方法与边界

这是从原工具方法提取的通用交接说明。原操作者的授权、岗位、账号、实例验收、私人路径和群范围不随源码转移；新安装按自己的实际职责与合法工具权限使用。普通接口合同只维护在[OPERATIONS-API.md](OPERATIONS-API.md)，读取合同见[TOOL-API.md](TOOL-API.md)。

## 先分清读取、动作与业务理解

读取工具提供准确账号、peer、serverId、发送人、原时间和覆盖收据；它不决定待办、参与、付款或业务完成。serverId是消息身份，localId可能复用。卡片标题、合并摘要、图片占位和资源元数据不等于原件或内件已读。只在已授权来源及本轮需要的窗口取得必要资料，别为单群问题导出全账号。

操作工具内部仍使用官方Linux微信、原生窗口/输入、离线OCR与原生消息核验，不是直接替代微信的私有网络协议。源码和某个动作名存在不等于任意联系人、布局、历史媒体或新账号已跑通。当前公共capabilities与实际配方返回的证据决定边界。

## 正常程序调用

通过host/tools/wechat_operations.py或同一AUP CLI提交明确的client、peer、稳定request_id、action与冻结payload。client是归属标签，不是权限租户；来源内容和优先级不授予业务权限。原文件先upload_file，再按业务条件核最新来源后准入。批量接口、manual与显式verified_fast复用原队列、guard、预览和原生核账。

manual先核实际最终预览，再confirm或cancel。verified_fast只有当前普通三动作能被程序正向验证才执行；异常转review_required或安全失败。pending继续查询原单；unknown只查或reconcile原请求，不能换ID补发。已accepted但清理待核是已发后的恢复，不能重发业务。

## 需要官方现场时

SDK误拒或尚无稳定配方时，已具本实例操作授权的人员/AI可按当前工具指引使用原官方客户端维护入口；不能把本说明当新增授权或保证所有场景可行。临时桌面入口host/tools/wechat_desktop.py无参数只帮助，view、navigate、compose分别按需要显式启用；普通程序发件不需要预先开启桌面。

先看原队列、真实ownership、共享内核guard和窗口状态。uiBusy=false或一个过期心跳不是独占权；合法维护必须实际取得原有保护，就绪业务优先。不得为进入维护取消别人请求、关闭别人会话、清别人草稿或跳过unknown。保护条件变化后停在可证明安全的小步边界，结束只清自己的现场并释放。

每步根据当前真实AX/截图或已验证原生窗口字段决定。官方进程、父窗、完整标题、真实peer/在群关系与冻结现场须互相对应，未知/同名/截断/布局漂移时保留缺口。不按相似名字或固定旧坐标猜人，不把互联网结果当联系人，也不以改绑定签名代替身份核验。

普通导航只用当前可证控件，焦点与窗口变化后重新观察。输入、原生剪贴板或SaveAs沿已存在且适用的受控函数，不把路径/名字误粘贴到聊天编辑器。不要盲Esc或用Enter猜发送；终端动作只在目标、内容、授权和本次预览已证后做一次。发件和只读导出各核自己的收据。

## 原件与收尾

只读导出优先用save_attachment的真实peer/source_id。原图取得须来源/资源身份成立、真实格式可解码，并明确原消息MD5、origin变体或官方显示截图各自的证明范围；密文、缩略图和屏幕截图不能冒充字节一致原件。受限路径失败就保存准确缺口，不读访问凭据、换账号或开发新解密器作为默认恢复。

只关闭本请求可证明拥有的查看器、保存框、临时聊天窗或搜索面板；原窗口和外来草稿保留。单击后立即看结果，不拿旧截图执行下一步。清理未证要留收据和恢复条件，不手改任务数据库为成功。官方客户端退出、权限/认证拒绝或来源一致性失败时按实际条件恢复；不把界面可见、上传或接口接受称为真人实收。

本包只做静态交付与合成离线检查，不启动真实桌面/监听/定时，不携带账号、目标绑定、消息、截图或模型。新环境的真实连接和收发需另验，不能用原实例的历史成功替代。
