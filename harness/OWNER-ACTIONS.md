# 本人私聊的受控动作网关

动作网关让本人私聊能执行少量预先配置、显式确认的固定命令，用于备份、同步、
生成报告一类可复用的个人动作。它不是通用 shell，也不接受聊天里的参数：命令、
工作目录、超时和环境都由私有配置文件预先固定。

只有原生身份已确认的本人私聊、普通文字消息会进入这里。好友、群聊、网页、
引用、图片文字和其他发送者都不能准备或确认动作；模型生成的内容也不能代替本人
确认。命令的准备、确认、取消和查看由触发器直接处理，不经过模型。

## 配置

在本人回复服务的私有状态目录放置 `actions.json`（与 `inbox.sqlite`、`voice-intake.json`
同目录），权限保持 0600、归运行用户所有。示例：

```json
{
  "version": 1,
  "actions": {
    "backup-notes": {
      "description": "备份本人笔记到本地备份目录",
      "command": ["/usr/bin/rsync", "-a", "/home/me/notes/", "/home/me/notes-backup/"],
      "cwd": "/home/me",
      "timeout": 30
    },
    "publish-report": {
      "description": "生成并检查本周报告",
      "command": ["/home/me/bin/weekly-report"],
      "timeout": 60,
      "env": {"REPORT_LOCALE": "zh_CN.UTF-8"}
    }
  }
}
```

约束：

- `command` 是固定的 argv 列表，不经过 shell；第一项必须是绝对路径且可执行。
- `cwd` 必须是绝对路径；省略时为私有状态目录。`timeout` 为 1–60 秒，默认 20 秒。
- `env` 只补充少量环境变量；`LD_PRELOAD`、`LD_LIBRARY_PATH`、`PYTHONPATH`、
  `PYTHONSTARTUP`、`BASH_ENV`、`NODE_OPTIONS` 等注入类变量会被拒绝。不要在命令
  输出里打印凭据、密码或完整环境。
- 最多 32 个动作。动作定义、描述、命令、目录、超时和环境一起参与摘要；准备后
  修改配置，旧确认编号会失效，需要重新准备。
- 配置缺失或格式错误时，动作命令只返回配置不可用，普通聊天不受影响。

## 使用

在本人私聊中发送：

- `动作 列表`：列出已配置动作和当前待确认编号。
- `动作 准备 backup-notes`：生成一个 16 位一次确认编号，30 分钟内有效。
- `动作 确认 <编号>`：执行一次，返回退出码、耗时和截断后的输出。
- `动作 取消 <编号>`：取消待确认动作，不执行。
- `动作 查看 [编号]`：查看待确认和最近记录；带编号时查看该条结果。

准备编号和确认编号都必须是新的原生本人文字消息。确认不以消息里的“同意”二字
或模型判断为依据，只认完整编号。每个编号最多执行一次；重复确认只返回原状态，
不会再次运行。配置变化、过期、取消、超时、进程中断和非零退出都不会自动重试；
进程中断后记录为“状态未知”，由本人查看后重新准备。

动作在回复工作进程中同步执行，默认最多 20 秒、上限 60 秒，期间会延迟同一
回复循环的后续消息。耗时更长的工作应继续走工程任务会话，不要放进动作网关。

## 审计与输出

每条动作记录写入本人 inbox 数据库的 `owner_actions` 表，包含动作名、状态、原消息
编号、确认消息编号、时间、退出码、耗时、输出摘要和截断标记；最多保留 200 条终态
记录。命令输出最多捕获 64 KiB，聊天里和数据库里都只保留前 2,000 字；需要完整
日志时，让命令自己写入私有位置并返回路径或摘要。

只读查看入口：

```sh
python -m rsi_agent action review --db /private/state/inbox.sqlite
python -m rsi_agent action review --db /private/state/inbox.sqlite --show-output
```

默认不显示输出摘要，也不显示命令 argv；`--show-output` 才显示已保存的截断输出。
入口不准备、不确认、不执行任何动作，确认仍只走原生本人私聊。

## 运行用户与边界

动作以本人回复服务所用的 `wechat-gui` 用户执行，能访问的文件和程序由该用户权限
决定。需要访问其他用户、挂载点或凭据时，应写一个受审查的绝对路径脚本，由本人
配置为动作，不要把密码放进聊天或仓库。动作配置、数据库和输出留在私有状态目录，
不进入 Git、共享偏好或其他会话。

当前版本只支持本地固定命令；没有 HTTP、邮件、日历、支付或任意参数适配器，也
没有定时触发、自动批准或后台重试。需要这些能力时另开适配器和授权设计，不把
动作网关扩大成通用执行器。

定向测试见 `tests/test_actions.py`（准备、确认、取消、过期、配置变化、超时、
输出上限、无 shell、审计和只读入口），本人回复循环的接线见
`tests/test_owner_memory.py` 中的 Linux 用例。真实微信验收只使用新的授权本人
入站和本人实际配置的动作，不在生产会话里插入测试命令。
