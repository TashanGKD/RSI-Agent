# 本人私聊的上下文总预算

本人私聊每轮会把身份/已读群上下文、命名记忆、知识片段和最近三轮对话拼成
一份输入。`trigger/owner_context.py` 给这份输入加一个统一的字节预算，默认
16 KiB，另留 256 字节给省略提示。分项上限仍由记忆和知识各自维护，本层只
决定总量超限时先放弃什么。

优先级固定为：

1. 身份与显式读取的群上下文：必需，超预算也保留，不静默截断。
2. 命名记忆：整组注入，放不下就整组省略，不拆开系统说明和用户数据。
3. 知识片段：同上，整组省略。
4. 最近三轮对话：从最新往旧加，先省略较早的轮次。

完全相同的消息只注入一次。发生省略时，末尾追加一条系统说明，写明“不要
声称看过省略的对话或资料”。附件、网页读取结果和工具权限不经过这个预算，
仍按原有协议单独校验；本层不新增存储、检索方式、身份或发送权限。

预算和优先级只影响本轮上下文，不改变已保存的原消息、记忆、知识索引或
发送回执。定向测试见 `tests/test_owner_context.py`；本人回复循环的接线在
`trigger/owner_reply.py`。
