# 本人私聊的命名记忆

仅在原生身份已确认的持续本人私聊中使用：

- `记住 风格：技术讨论直接讲机制`：保存一条；同名内容再次发送即更正。
- `查看记忆` 或 `查看记忆 风格`：查看当前内容。
- `忘记 风格`：从当前命名记忆中移除。

应用直接处理这些命令，无需模型生成或执行工具。内容保存在本会话已经绑定身份的私有
inbox SQLite 中，不写入 Git、共享 preferences.md 或其他群的数据库。普通群聊、引用卡片、
图片文字和其他发送者不能使用这条写入路径。首版是命名查询与更正，没有自动画像、
跨群合并、语义检索或新的 DSH 插件包。最多 16 项、合计 8192 UTF-8 字节。
命名记忆只用于本人私聊答复，不自动加入工程执行输入或项目 PR。

保存/更正/忘记与原消息的回复缓存处于同一事务。SourceInbox ACK、原 ID、V2 发送流程
不变；中断后复用原缓存，不再执行一次记忆修改或另发回复。新 `/codex` 路径仍按原选择
规则排队，不由命名记忆接管。

更正或忘记后，后续普通聊天使用新的 SDK 会话范围，并排除此前历史片段。旧请求的
冻结输入/SDK 会话/结果、原始聊天和投递回执继续保留；“忘记”不表示删除这些历史记录。
同一未完成原请求仍读取它已经冻结的输入，不用新记忆替换或重跑。其他会话使用独立的
原生身份和 SDK 范围；普通群流程不打开私聊记忆表。
如果该原消息已经有冻结的 SDK 输入，仍沿原生成/缓存路径收束，不重新解释为记忆命令。

首版首次激活后的回滚必须检查是否已有真实记忆变更。旧版本不支持该表/会话分代时，
不能在新记忆已生效后自动切回旧会话或回滚私有数据库。保持新源码和原回执待复核。
隔离生命周期/事务/身份/SDK 输入测试见 `tests/test_owner_memory.py`。真实微信命令验收
只认新的授权本人入站，不插入生产测试消息。
