# 本人私聊的命名记忆

命名记忆只放简短、显式、长期有效的事实、偏好和承诺。大段资料、项目说明和可检索文档
放到[私有知识索引](OWNER-KNOWLEDGE.md)，不要写进这里；两套内容都只服务本人私聊。

仅在原生身份已确认的持续本人私聊中使用：

- `记住 风格：技术讨论直接讲机制`：保存或更正一条未分类记忆。
- `记住[偏好] 风格：技术讨论直接讲机制`：带类型保存或更正；可用类型为
  `未分类`、`身份`、`偏好`、`关系`、`承诺`、`事实`、`项目`。未写类型时沿用原类型，
  新条目为 `未分类`。
- `查看记忆` 或 `查看记忆 风格`：查看当前内容、类型和更新时间；到期条目标为“待复核”。
- `忘记 风格`：从当前命名记忆中移除。

## 类型、复核与注入范围

- 来源是原生的本人私聊消息 ID；条目只保存在本会话已绑定身份的私有 inbox SQLite 中，
  scope 固定为 `owner`。
- `承诺` 默认 30 天、`事实` 180 天、`项目` 90 天后进入待复核；`身份`、`偏好`、`关系`、
  `未分类` 不自动到期。到期只停止自动注入，不删除原文；再次发送同内容可续期，
  `查看记忆` 仍可看到并标明待复核。这不是定时提醒。
- 单条最多 1200 字；最多 16 条、合计 8192 UTF-8 字节。像密钥、密码或令牌的内容不会被保存。
- 自动上下文只取未到期且与本轮输入相关或属于长期偏好的条目，最多 8 条、
  4096 UTF-8 字节；未列出的记忆仍保存在私有库，不表示不存在。
- 没有自动画像、跨群合并、外部向量库或从聊天内容推断新记忆；类型只来自本人的显式命令。
- 只读查看入口：
  `python -m rsi_agent memory review --db <private inbox.sqlite> [--query ...] [--show-values]`。
  它不写入；新增、更正和忘记仍只走原生本人私聊。

应用直接处理这些命令，无需模型生成或执行工具。内容不写入 Git、共享 `preferences.md`
或其他群的数据库。普通群聊、引用卡片、图片文字和其他发送者不能使用这条写入路径。

保存/更正/忘记与原消息的回复缓存处于同一事务。SourceInbox ACK、原 ID、V2 发送流程
不变；中断后复用原缓存。旧 `/codex` 请求仍可核对自己的原记录。

更正或忘记后，后续 Codex 输入只纳入更新后的命名记忆，排除此前的历史片段。旧请求的
冻结输入、结果、原始聊天和投递回执继续保留。
同一未完成原请求仍读取它已经冻结的输入，不用新记忆替换或重跑。其他会话使用独立的
原生身份和会话范围；普通群流程不打开私聊记忆表。
如果该原消息已经有冻结的 Codex 输入，仍沿原生成/缓存路径收束，不重新解释为记忆命令。

首次激活后的回滚必须检查是否已有真实记忆变更。旧版本不支持该表/会话分代时，
不能在新记忆已生效后自动切回旧会话或回滚私有数据库。保持新源码和原回执待复核。
隔离、迁移、类型、复核期、预算与只读入口测试见 `tests/test_memory.py`；事务和
Codex 输入边界见 `tests/test_owner_memory.py`。真实微信命令验收只认新的授权本人入站，
不插入生产测试消息。
